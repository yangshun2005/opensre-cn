在报告对比列中使用以下提供的数值。这些是冻结的产品基准，标注为 **2026-09-11** 在 **30 天**内测得，并非用户分析期间实时测量的数据。

|---|---:|---:|
| main 分支红灯时间占比 | 7.5% | 31.6% |
| 平均恢复绿灯时间 | 9.0h | 4.3h |
| CI 导致的失败率 | 1.9% | 1.6% |
| 最慢正常运行 | 4m | 20m |
| PR 失败率 | 11.5% | 54.6% |

快照来源：2026-09-11 随 `integrations/github/tools/ci_analytics/benchmarks.py` 发布的 `BENCHMARKS`、`MEASURED_ON` 和 `WINDOW_DAYS` 数据。本参考收录这些数值，使技能无需导入或运行报告实现即可使用。原始对等记录和覆盖率详情未随此快照打包。

## 解读

对比 `metrics.md` 中定义的归一化形式：红灯占比、恢复小时数、同 SHA 恢复率、最慢工作流基线、PR 运行失败率。将目标仓库放在首位。原始执行次数、受影响作者和工作时长取决于仓库和团队规模，此处无对等对比。

表格标题需注明基准日期和窗口。将这些数字视为历史背景，而非受控排名：工作负载不同，且旧测量的边界与重试处理无法从本快照验证。若目标使用其他报告窗口或某指标缺少覆盖，需在对比旁说明。目标覆盖率缺口不改变所提供的对等数值。

快照仅使用一次；收集新的对等历史是另一项工作，仅在用户明确要求刷新对比时进行。
